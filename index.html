NEO // POSTER HOMEPRIVACYTERMS

Automated publishing
for NEO's own content.

NEO Poster is a desktop app that turns NEO's gameplay clips and outfit pictures into scheduled posts, then publishes them to NEO's own accounts through each platform's official API, on a steady, rate-limited schedule.

HOW IT WORKS

01

CAPTURE

Screenshots and clips from the NEO Roblox experience land in a local folder.
02

PREPARE

Outfit pictures are cropped and framed automatically. Videos stay untouched at full quality.
03

SCHEDULE

Each post gets a title, caption and hashtags, then the next free slot inside the active hours.
04

PUBLISH

At its slot, the post is sent through the official API of each platform it targets.

Signs in only to NEO's own accounts. It never reads followers, messages, comments or other users' data.

Runs entirely on the NEO team's computer. There is no NEO Poster server, database or cloud copy.

Rate limits are built in: a daily cap per platform and a minimum gap between posts, so it never floods a feed.

Every account link can be removed at any time from the platform's own settings.
